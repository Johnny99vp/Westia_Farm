# Westia AgroMarket frontend
React + TypeScript + Tailwind + React Router + Lucide.
    npm install && npm run dev
All data is DEMO data in the browser (src/lib/db.tsx, localStorage). Nothing is secure or shared. Replace each mutation in db.tsx with Supabase queries / Edge Function calls.
Demo admin: Account > Security > "Turn admin preview on" (remove before production).
Never put service-role or payment secret keys in this project.
